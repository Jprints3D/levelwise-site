# Levelwise public site

Static privacy, support, and intro pages for [Levelwise](https://github.com/Jprints3D/XPTracker).

Live:

- https://jprints3d.github.io/levelwise-site/
- https://jprints3d.github.io/levelwise-site/privacy.html
- https://jprints3d.github.io/levelwise-site/support.html

The iOS/Android clients point at these URLs (`Config.privacyPolicyURL` and `Config.supportURL`). Content on these pages can change without an app update.

A support email has not been set. Do not invent one; until it is added, users are asked to open a GitHub issue.
